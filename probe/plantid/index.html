Plant ID: can this phone run the model?

This page tests whether the plant-identification model (BioCLIP 2.5, the most accurate one) runs on this phone, straight in Safari. It downloads the model once (1.3 GB, so use Wi-Fi), keeps it on the phone, and then names three test photos. Keep Safari open and the screen on until it says it's done (a few minutes).

If the page reloads by itself or Safari shows “A problem repeatedly occurred”, that is a result too: just open this page again and press Copy results.
